## Data Flow

```
page.tsx (server)
  → requireRole(['coach'])
  → sql`SELECT students WHERE dojo_id = ${dojoId}`
  → <StudentDataTable students={rows} />
      → student-actions.tsx (row actions)
      → student-dialog.tsx (add/edit form)
          → createStudent() / updateStudent() server action
          → revalidatePath('/dashboard/students')
```

## Key Types

```ts
// From src/types/database.ts
interface Student {
  id: string;
  dojo_id: string;
  guardian_account_id: string | null;
  name: string;
  gender: 'male' | 'female';
  date_of_birth: string | null;   // ISO date string
  weight: number | null;          // kg
  rank: string | null;
  registration_no: string;        // auto 'SK26-0001'
  photo_url: string | null;
  is_active: boolean;
  dob_locked: boolean;
  created_at: string;
}
```

---

## Rank Values (Enum)

Valid rank strings: `'white'`, `'yellow'`, `'orange'`, `'green'`, `'blue'`, `'brown_3'`, `'brown_2'`, `'brown_1'`, `'black_1'`, `'black_2'`, `'black_3'`

---

## Important Business Rules

1. **`registration_no`** is auto-generated by DB trigger — never set manually
2. **`dob_locked`** becomes `true` once the student's first entry is submitted to organiser — after that, DOB cannot be edited
3. **`is_active`** is auto-recalculated by `evaluate_dojo_students_activity()` trigger on entry changes
4. **`guardian_account_id`** is null for legacy/manually-added students
5. Photos: compress with `@/lib/image-compression` before upload, store URL in `photo_url`

---

## Filtering & Sorting (in student-data-table.tsx)

- Columns: name, gender, rank, weight, registration_no, is_active
- Search: fuse.js fuzzy search on name + registration_no
- Rank filter: multi-select dropdown
- Active filter: active/inactive/all toggle
- Pagination: client-side via TanStack Table

---

## Bulk Upload Format

Expected Excel/CSV columns (case-insensitive):
`Name`, `Gender`, `Date of Birth` (DD/MM/YYYY), `Weight`, `Rank`

- Validation happens in `student-bulk-upload.tsx` before submission
- Uses `xlsx` package for parsing
- Duplicate detection by name + DOB within same dojo
